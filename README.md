# Paradise Nursery

Paradise Nursery is a React shopping cart application for browsing and purchasing houseplants. It includes a landing page, grouped plant catalog, dynamic cart count, quantity controls, deletion, totals, and checkout placeholder.

## Project files

- `src/App.jsx` — landing page and application flow
- `src/components/AboutUs.jsx` — company information
- `src/components/ProductList.jsx` — categorized plant catalog
- `src/components/CartItem.jsx` — shopping cart view
- `src/redux/CartSlice.jsx` — cart reducer functions
- `src/App.css` — landing page background and responsive styles
